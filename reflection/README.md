# Reflection cá nhân

Mỗi thành viên sao chép `TEMPLATE.md` thành một file riêng:

```text
reflection/<ma-hoc-vien>-<ten-khong-dau>.md
```

Không viết chung một bản cho cả nhóm. Mỗi người phải giải thích được phần mình đứng tên trong README, spec và demo.

## Checklist

- [ ] Mỗi thành viên có đúng một file.
- [ ] Có bằng chứng cụ thể: file, commit, eval case hoặc feedback ID.
- [ ] Nêu ít nhất một quyết định đã thay đổi sau khi nhìn vào dữ liệu.
- [ ] Nêu một lỗi/thất bại thật và bài học rút ra.
- [ ] Không chứa API key, dữ liệu cá nhân nhạy cảm hoặc chatlog dài.
